Todos traen esqueleto y animaciones (Idle, Walk, Sitting, Standing, Death, entre otras).
Los colores van por material, sin texturas: para un borrado basta cambiar el color del material.

Cómo cargarlos (GLTFLoader viene con three, no es dependencia nueva):

  import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
  const gltf = await new GLTFLoader().loadAsync(import.meta.env.BASE_URL + 'modelos/oficinista.glb');
  ctx.stage.add(gltf.scene);
  const mixer = new THREE.AnimationMixer(gltf.scene);
  mixer.clipAction(gltf.animations.find((a) => /Idle$/.test(a.name))).play();
  // en update: mixer.update(dt)

Vienen en escalas distintas: medir la altura y escalar a 1,7 m aprox.
Para repetir un modelo muchas veces (multitud), clonar con SkeletonUtils.clone
de 'three/addons/utils/SkeletonUtils.js'.
